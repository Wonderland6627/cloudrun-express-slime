# 生产环境域名配置指南

## 🌐 默认域名 vs 自定义域名

### 默认域名特点

**您的默认域名**：`express-slime-216111-7-1352845565.sh.run.tcloudbase.com`

#### ✅ 可以使用的情况：
- **开发测试环境**：完全可以使用
- **内部测试**：团队成员测试使用
- **功能验证**：验证API功能是否正常

#### ⚠️ 不建议用于正式上架的情况：
- **生产环境**：不推荐用于正式上架
- **用户面向的应用**：域名过长且不友好
- **品牌形象**：默认域名不够专业

### 默认域名的限制

1. **域名长度**：默认域名通常很长，不便于记忆和分享
2. **品牌形象**：使用默认域名显得不够专业
3. **SEO影响**：对搜索引擎优化不友好
4. **用户体验**：用户难以记住和输入

## 🎯 正式上架建议

### 方案一：配置自定义域名（推荐）

#### 步骤：

1. **准备域名**
   - 购买一个自定义域名（如：`api.yourgame.com`）
   - 确保域名已备案（如果使用国内服务器）

2. **在云托管配置自定义域名**
   - 登录 [腾讯云托管控制台](https://console.cloud.tencent.com/tcb)
   - 进入您的服务详情页
   - 点击 **"域名管理"** 标签
   - 点击 **"添加域名"**
   - 输入您的自定义域名
   - 按照提示配置DNS解析

3. **DNS配置**
   - 在您的域名DNS管理中添加CNAME记录
   - 记录值指向云托管提供的CNAME地址
   - 等待DNS生效（通常几分钟到几小时）

4. **SSL证书**
   - 云托管会自动为自定义域名配置SSL证书
   - 支持HTTPS访问

#### 优势：
- ✅ 专业、易记的域名
- ✅ 提升品牌形象
- ✅ 更好的用户体验
- ✅ 支持HTTPS（自动配置）

### 方案二：使用默认域名（仅限测试）

如果暂时无法配置自定义域名，默认域名可以用于：
- 开发测试阶段
- 内部功能验证
- 临时演示

**注意**：正式上架前务必配置自定义域名。

## 📝 域名使用示例

### 使用默认域名测试：

```bash
# 基础URL
BASE_URL="https://express-slime-216111-7-1352845565.sh.run.tcloudbase.com"

# 测试获取用户信息
curl -X POST ${BASE_URL}/api/minigame/getUserGameInfo \
  -H "Content-Type: application/json" \
  -H "x-openid: test123" \
  -d "{}"
```

### 使用自定义域名（配置后）：

```bash
# 基础URL（示例）
BASE_URL="https://api.yourgame.com"

# 测试获取用户信息
curl -X POST ${BASE_URL}/api/minigame/getUserGameInfo \
  -H "Content-Type: application/json" \
  -H "x-openid: test123" \
  -d "{}"
```

## 🔒 安全建议

1. **HTTPS必须**：无论使用默认域名还是自定义域名，都应使用HTTPS
2. **API密钥保护**：不要在客户端暴露敏感信息
3. **请求频率限制**：建议添加API请求频率限制
4. **CORS配置**：正确配置跨域访问策略
